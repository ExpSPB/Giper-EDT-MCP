# impact_analysis

Review direct metadata and indexed BSL usages before changing one metadata object. Parameters and examples: get_tool_guide('impact_analysis').

## Parameters
| Parameter | Required | Type | Description |
| --- | --- | --- | --- |
| projectName | yes | string | EDT project name |
| objectFqn | yes | string | Top-level object FQN, e.g. Catalog.Products. The type token may be English or Russian. Use the programmatic name, not the synonym. |
| action | — | string (one of: modify, rename, delete) | Planned change (default modify) |
| skipBsl | — | boolean | Search only metadata when true (default false) |
| limit | — | integer | Overall reference limit, 1-500 (default 100) |

## Guide
Review direct usages of one top-level metadata object before modifying, renaming, or deleting it. The query reads the named project and includes indexed BSL usages by default. Set `skipBsl: true` to search metadata only.

For example, pass `projectName`, `objectFqn: "Catalog.Products"`, and `action: "rename"`. The type token may also be `Справочник`. Use the programmatic object name.

The report identifies the scope, the planned action, and known sources and features. BSL rows include a module and a line when available. A completed search reports the exact count and a usage-based severity of LOW for zero, MEDIUM for 1–10, or HIGH above 10. The estimate applies to the stated static-search scope.

The search budget is 45 seconds. When the work stops early or available data is incomplete, the report gives a lower bound and the reason. Severity and recommendations require a complete search. Use `dependency_graph` for transitive dependencies.
