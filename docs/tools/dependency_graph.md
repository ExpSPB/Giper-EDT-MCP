# dependency_graph

Trace direct and transitive metadata dependencies and cycles from one object. Parameters and examples: get_tool_guide('dependency_graph').

## Parameters
| Parameter | Required | Type | Description |
| --- | --- | --- | --- |
| projectName | yes | string | EDT project name |
| objectFqn | yes | string | Top-level object FQN, e.g. Catalog.Products. The type token may be English or Russian. Use the programmatic name, not the synonym. |
| direction | — | string (one of: in, out, both) | Incoming, outgoing, or both (default both) |
| depth | — | integer | Maximum distance in edges from the root, 1-5 (default 2) |
| maxNodes | — | integer | Vertex limit including the root, 1-2000 (default 200) |
| maxEdges | — | integer | Unique directed edge limit, 1-5000 (default 500) |

## Guide
Walk the selected project's metadata from one top-level object. Use `direction=out` for dependencies, `direction=in` for dependents, or `direction=both` to explore both directions from each visited vertex.

For example, call with `projectName`, `objectFqn: "Catalog.Products"`, `direction: "in"`, and `depth: 2`. The same root can be addressed as `Справочник.Products`. Use the programmatic object name.

The JSON result contains canonical FQNs and distances in `nodes`, directed links in `edges`, and strongly connected groups in `cycles`. Each link goes from the referring object to its target even during an incoming walk. Links of the same kind (`via`) between the same pair share a row. The `count` counts distinct reference occurrences, including references held by separate attributes. A cycle can contain one node with an explicit self-reference.

`maxNodes` counts vertices including the root. `maxEdges` counts unique directed links. The time budget is 45 seconds, including preparation. The reader checks the budget between reference reads, and EDT may finish a native read already in progress. If a limit stops the work or part of the model could not be read, `partial` is true and `partialReasons` describes why. Requested depth defines the scope. The cycle list describes the returned graph. Use `impact_analysis` for a direct usage report including indexed BSL.
